# Dados do Factory Vision

Este diretório existe apenas para documentar a política de dados do projeto.

Vídeos reais da fábrica, imagens de funcionários e qualquer material interno ou
sensível devem permanecer fora do repositório público. Credenciais, senhas,
endereços de câmeras e outros dados de acesso também nunca devem ser armazenados
aqui.

Para desenvolvimento e testes, use somente dados artificiais, públicos e
devidamente licenciados ou anonimizados. Caso seja necessário trabalhar
localmente com dados privados, armazene-os em `data/private/`, que está protegido
pelo `.gitignore`, e aplique os controles de acesso adequados fora do Git.
